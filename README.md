## 🚀 Featured Projects

### 🔗 ChainGuard
Blockchain-based digital evidence chain-of-custody system. Every handover of digital evidence is recorded on an immutable ledger so investigators, courts and auditors can verify evidence was not altered.

- Tamper-evident custody log
- Evidence hashing for integrity verification
- Role-based access and full audit trail
- QR code generation and webcam scanning for evidence IDs

**Stack:** Node.js, Express, MongoDB, Solidity, Hardhat, Ganache, Ethers.js

> 🔒 The repository is private while the project is in development. A public showcase and demo are coming soon.
